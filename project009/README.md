# Жоба 009 — Almas Official Edition

Жоба 009 үшін Almas Official модификация қабаты.

## Негізгі өзгерістер

- **Almas Official** атауы, авторлық метадерек және бренд конфигурациясы.
- Қара/шыны (glass) + neon акцентке негізделген `WOW` визуал бағыты.
- **AO Coin**, **Gold**, **Bank** және **Reputation** экономикасы.
- Күнделікті сыйақы, жұмыс/миссия төлемдері, дүкен, банкке салу/алу және транзакция тарихы.
- Баланс теріс мәнге түспейді; барлық ақша қозғалысы ledger арқылы тіркеледі.
- XAPK/APK ішіне Project 009 метадерегін енгізуге және Android app label-ін `Almas Official` атауына ауыстыруға арналған патчер.

## Құқық туралы

`project009/` ішіндегі жаңа код, конфигурация және **Almas Official** брендинг қабаты — Project 009 өзгерістері ретінде бөлектенеді.

> Маңызды: бастапқы ойынның коды, модельдері, карталары, дыбыстары немесе басқа үшінші тарап материалдары автоматты түрде Almas Official авторлық меншігіне айналмайды. Бұл репозиторий тек осы branch-та қосылған жаңа модификация қабатын белгілейді. Бастапқы материалдардың құқықтары олардың тиісті иелерінде қалады, егер бөлек құқық берілмесе.

## Құрылым

- `config/project009.json` — бренд және экономика параметрлері.
- `economy.py` — локал экономика ядросы.
- `patch_project009.py` — XAPK/APK ребрендинг патчері.
- `NOTICE.md` — Project 009 авторлық ескертуі.

## Патчерді пайдалану

```bash
python project009/patch_project009.py game.xapk --output Project009-AlmasOfficial.xapk
```

Патчер:

1. XAPK-ты ашады.
2. Base APK-ты табады.
3. `apktool` бар болса, APK ресурстарын decode жасайды.
4. Қолданба атауын `Almas Official` деп өзгертеді.
5. `assets/project009/` ішіне бренд және экономика конфигурациясын енгізеді.
6. APK-ны қайта жинайды.
7. `apksigner` кілті берілсе, қол қояды.
8. Жаңартылған XAPK құрады.

## Экономика

Әдепкі валюталар:

- `AO Coin` — негізгі валюта.
- `Gold` — premium валюта.
- `Bank` — банк балансы.
- `Reputation` — прогресс/бедел.

Экономика коды барлық операцияны локалды JSON ledger-ге жазады және кейін Unity/Android runtime bridge арқылы ойын UI-ына қосуға дайын етіп жасалған.
